{%- comment -%} The fun.limited splash. The word cycles through ten display faces and ten palette colours, one step every 200 ms, and lands on Permanent Marker in ink. Ten steps is two seconds, which is the length the original Google Sites version ran. Settled 12 September 2026: 200 ms, all ten colours, spread order, each face once, brightened ochre kept in. Three things about how this is built: * The overlay is created by this script, not written into the page. A visitor with no JavaScript, and every search engine, sees the site with no splash and nothing hidden behind one. * It runs once per browsing session, so moving between pages does not set it off again. * It waits for the faces to download before flashing anything. A face that has not arrived falls back silently, which is what made the original look wrong on a slow connection. If the faces take longer than 1.2 seconds the splash gives up and lifts, and the visitor simply sees the site. * Every face is a file this site serves. Nothing depends on what happens to be installed on the visitor's machine, so the sequence looks the same on Windows, on a Mac and on an Android phone. {%- endcomment -%}
